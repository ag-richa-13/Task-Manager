# TaskFlow - Backend (Node.js + TypeScript + Prisma + PostgreSQL)

This repository contains a complete backend for TaskFlow: authentication (JWT access + refresh), task CRUD with pagination/filter/search, TypeScript, Prisma ORM and PostgreSQL.

---

## Quick setup (development)

1. Clone or create `backend/` folder and add files described.

2. Install dependencies:

```bash
cd backend
npm install
```
